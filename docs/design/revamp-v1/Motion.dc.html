Motion spec
Rules: transitions 250–350 ms · feedback ≤150 ms · entrances ease-out, exits ease-in and ~30% shorter · exaggeration ≤5% · one thing moves at a time · identical actions animate identically · transform/opacity only · reduced-motion → opacity-only, no loops. Built for Reanimated 4 (spring damping 18, stiffness 220 for settles).
