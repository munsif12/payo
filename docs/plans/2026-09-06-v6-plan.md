# PAYO v6 Implementation Plan (guardian, scam interruption, proactive greeting)

> Subagent-driven: one implementer per phase, independent review per phase, orchestrator
> commits. **Spec (binding):** `docs/2026-09-06-payo-v6-guardian-scam-proactive-design.md`.

## Global constraints
Roadmap + v2–v5 constraints. Money never moves without PIN; approval and check-in are
additional gates in the same execute path. `cards.py` ↔ `cardShapes.ts` parity gate. Guardian
approval uses the guardian's PIN via the shared `assertPinOk` (lockout inherited). Nothing pushed.
